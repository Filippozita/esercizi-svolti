Prova il calcolatore: Calcolatore media, mediana, varianza e deviazione standard

1. Indici di posizione

Media x̄ = Σxᵢ / n   Media ponderata Σxᵢfᵢ / Σfᵢ
Mediana: valore centrale dei dati ordinati (n dispari: posizione (n+1)/2; n pari: media dei due centrali)
Moda: valore più frequente

2. Indici di variabilità

Varianza σ² = Σ(xᵢ − x̄)² / n   campionaria s² = Σ(xᵢ − x̄)² / (n − 1)
Formula di calcolo: σ² = Σxᵢ²/n − x̄²   Scarto quadratico medio σ = √σ²
Coefficiente di variazione CV = σ / x̄   Campo di variazione max − min   IQR Q3 − Q1

3. Distribuzioni di frequenza

Frequenza relativa fᵢ / N; cumulata = somma progressiva. Con classi si usa il valore centrale.

4. Probabilità

P(A) = casi favorevoli / casi possibili   P(A∪B) = P(A) + P(B) − P(A∩B)
Condizionata P(A|B) = P(A∩B) / P(B)   Indipendenza P(A∩B) = P(A)·P(B)
Bayes P(A|B) = P(B|A)·P(A) / P(B)

5. Binomiale e normale

Binomiale P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ, μ = np, σ² = np(1−p)
Normale standardizzata z = (x − μ) / σ; si usano le tavole di Φ(z). Regola empirica: 68% entro 1σ, 95% entro 2σ, 99,7% entro 3σ.

6. Regressione e correlazione

b = Sxy / Sxx, a = ȳ − b x̄, retta ŷ = a + b x
r = Sxy / √(Sxx · Syy), con −1 ≤ r ≤ 1; R² = r² = quota di varianza spiegata.

7. Intervalli di confidenza

Media con σ nota: x̄ ± zα/2 · σ/√n (z = 1,645 al 90%, 1,96 al 95%, 2,576 al 99%)
Con σ ignota e n piccolo si usa la t di Student con n−1 gradi di libertà.

Esercizio 1 — Indici di posizione
Voti di 10 esami: 18, 22, 25, 25, 27, 28, 30, 30, 30, 26. Calcolare media, mediana e moda.
Soluzione. Media = Σx/n = 261/10 = 26,10. Ordinati: 18, 22, 25, 25, 26, 27, 28, 30, 30, 30; n pari → mediana = media dei valori in 5ª e 6ª posizione = (26+27)/2 = 26,50. Moda = 30 (compare 3 volte).
Esercizio 2 — Varianza e deviazione standard
Con gli stessi dati calcolare varianza e scarto quadratico medio (della popolazione e campionari).
Soluzione. Σ(x−x̄)² = 134,90. Varianza popolazione σ² = 134,90/10 = 13,49, σ = 3,673. Campionaria s² = 134,90/9 = 14,99, s = 3,872. CV = σ/x̄ = 14,1%.
